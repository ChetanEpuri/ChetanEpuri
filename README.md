`EKS` `ArgoCD` `GitOps` `DevSecOps` `Terraform` `Prometheus`

**[EVENT-HORIZON](https://chetanepuri.github.io/EVENT-HORIZON)**  
Real-time gravitational lensing simulator. RK4 numerical integration of photon geodesics in curved spacetime. Pure JavaScript + Canvas, zero libraries, live telemetry panel.
