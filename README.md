### ⚫ [Event Horizon — Gravitational Lensing Observatory](https://ChetanEpuri.github.io/EVENT-HORIZON)
> *A physics engine in a browser. General relativity, rendered in real time.*

Interactive simulation of black hole gravitational lensing using **4th-order Runge-Kutta** numerical integration. Every photon path is computed from geodesic ODEs derived from general relativity.

```
θ ≈ 4GM / c²b   ←   Einstein deflection angle
```

- Real-time RK4 photon ray tracing with live telemetry
- Adjustable mass, relativity index, ray count, Einstein ring toggle
- Captures photon capture rate, max deflection, Schwarzschild radius live

**Stack:** `Vanilla JavaScript` `HTML5 Canvas API` `CSS3` `Physics/Math`
